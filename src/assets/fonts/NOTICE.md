# Bundled fonts

`MesloLGLNerdFontMono-*.ttf`: Meslo LG by André Berg (Apache License 2.0, https://github.com/andreberg/Meslo-Font),
patched by Nerd Fonts (MIT, https://github.com/ryanoasis/nerd-fonts). Bundled because WebKit does not expose
user-installed fonts to web content, so the terminals could not use an installed copy, and Nerd Font glyphs keep
shell prompts that use them readable.
